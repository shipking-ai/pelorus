What it does today

Small on promises, careful on defaults.

Workspaces that are really separate

Each workspace has its own cookies, cache, storage, history and permissions. Delete a workspace and its data goes with it. Private tabs live in memory only.

architecture →

A command palette for everything

Ctrl+K searches your tabs, history, bookmarks, workspaces and commands. Suggestions are computed on your computer; your keystrokes are never sent to a search provider.

Privacy you can see

Ad and tracker blocking, HTTPS-first with no way to click through a bad certificate, tracking-parameter stripping, Global Privacy Control, and deny-by-default permission prompts.

threat model →

Sleeping tabs, lazy restore

Inactive tabs can unload to free memory, and a restart loads only the tab you were looking at. On our two-run benchmark memory landed near Chrome's: a result with caveats, written up in full.

the numbers →

Downloads that don't bite

File names are sanitised, risky types are flagged (including disguised .pdf.exe), and the browser never launches an executable you downloaded.

No telemetry. Not even a little.

The only things Pelorus does by itself: fetch ad-blocker lists, and — only if you switch it on — secure-DNS lookups. The update check runs only when you press its button.

Built to be checked

Don't trust us. Verify.

Pelorus is not code-signed yet, so we give you better ways to check what you downloaded than a publisher name.

Check the download

Every release is built by GitHub Actions from a tag, with a checksum file, an SBOM and a build-provenance attestation.

gh attestation verify Pelorus-Setup-0.3.0.exe --repo shipking-ai/pelorus
Get-FileHash .\Pelorus-Setup-0.3.0.exe -Algorithm SHA256

  • 73 unit tests, including seeded fuzzing (it found five real bugs)

Where it stands

An honest pre-release.

Works today

  • Browsing, tabs, workspaces, private tabs, split view
  • Tracker blocking, HTTPS-first, permission prompts, safe downloads
  • Session restore, sleeping tabs, command palette, history and bookmarks
  • Per-user installer and zip for Windows x64

Not there yet

  • Extensions, sync and a password manager
  • Code signing (Windows will warn; verify the download instead)
  • An independent security review
  • Hands-on testing on macOS and Linux (CI passes; nobody has used it by hand)
  • Screen-reader testing: automated accessibility checks only, so far

The full status, open issues and roadmap live in the handoff document in the repository.
